## Reproduce

1. Stop any running instance of this project's JAR before rebuilding it.
2. Run `scripts/build.cmd` (or `mvnw.cmd clean verify` with a configured JDK).
3. In another terminal run `scripts/run.cmd` and leave it running.
4. Run `python tools/wadl_to_openapi.py --url http://localhost:8085/api/application.wadl`.
5. Run `python -m unittest discover -s tools -v`.
6. Run `npm.cmd ci --ignore-scripts`, `npm.cmd run api:validate`, and `npm.cmd run api:test`.
7. Follow the README's SoapUI, Swagger Editor, and Postman UI walkthroughs and capture your own screenshots if required for submission.
